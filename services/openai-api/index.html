Service Overview

What OpenAI API is, what it provides, and who it's built for — before the deeper facts and figures.

OpenAI API is a service that gives developers access to OpenAI's models to build intelligent apps and integrate AI into their products.

Rather than a single product, the API is a foundation for building custom AI applications — model access, developer documentation, integration tools and flexible pricing that scales from a first prototype to a production workload.

It sits underneath several of OpenAI's own consumer and business products, and is the same access path independent developers, startups and enterprise teams use to bring OpenAI's models into their own software.

"The API is not a single feature — it's direct, developer-facing access to the same models that power OpenAI's own products, priced and delivered for teams to build on."

— How OpenAI API is designed to work

Key limitations & restrictions

Important constraints to understand before integrating or relying on the OpenAI API.

Rate limits apply

Requests and token usage are subject to limits that can vary by model and usage tier.

Model-specific limits

Context size, output limits, supported tools, modalities, and capabilities differ between models.

Usage-based costs

Costs can vary based on the model, token usage, processing method, and additional tools used.

Regional restrictions

API access is available only from supported countries and territories.

Usage restrictions

Applications must comply with OpenAI's applicable Usage Policies and service terms.

Outputs require validation

AI-generated responses may need human review or verification when accuracy is important.

Limits and capabilities may change as OpenAI updates models, policies, and platform features.

Requirements & prerequisites

What users generally need before they can start accessing and integrating the OpenAI API.

OpenAI Platform account

An OpenAI Platform account is required to manage projects, API access, and platform usage.

API key

API requests require a secret API key for authentication and secure application access.

API billing or credits

API usage has separate billing from ChatGPT subscriptions and may require available API credits or billing setup.

Supported location

Users must access the API from a country or territory currently supported by OpenAI.

Integration environment

A backend, application, script, server, or another HTTP-capable environment is typically needed to send API requests.

Policy compliance

Applications and workflows must comply with applicable OpenAI policies, terms, and usage requirements.

Good to know — A ChatGPT subscription does not automatically include OpenAI API usage. API access and billing are managed separately.
